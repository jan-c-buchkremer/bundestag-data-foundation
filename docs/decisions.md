# Decisions

One line per decision, newest last. Date, decision, reason.

- 2026-09-21 — Ingest from primary sources (bundestag.de XML/XLSX, DIP API, abgeordnetenwatch), not from an existing corpus. All corpora stop in 2023 or are PDF-derived; the XML already carries speaker ids and separated interjections. (`landscape.md` §5)
- 2026-09-21 — The Bundestag MdB ID (`MDB/ID` = `redner/@id`) is the person primary key; DIP and abgeordnetenwatch ids are attributes. It is the only id that is present in both the protocol and the master data.
- 2026-09-21 — abgeordnetenwatch `ext_id_bundestagsverwaltung` is stored only when it agrees with a name+birth-year match. Verified wrong for 56/630 WP21 members.
- 2026-09-21 — Roll-call votes come from the bundestag.de XLSX, not from abgeordnetenwatch. Official, same-day, exact sitting/vote number; abgeordnetenwatch lags and has no structured Drucksache link.
- 2026-09-21 — Drucksache metadata and authorship come from DIP; the full author list via `/aktivitaet?f.drucksache=`, because `autoren_anzeige` is capped at 4. bundestag.de Open Data has PDFs only for WP21 Drucksachen.
- 2026-09-21 — Non-MdB speakers (ministers without mandate, Bundesrat, guests) get `person` rows with `is_mdb = 0`. They have ids in the XML anyway and are interesting for the fact sheet.
- 2026-09-21 — SQLite, single file, stdlib `sqlite3`; raw files kept unchanged under `data/raw/`. Home server, weekly batch, readers only need `sqlite3`. DuckDB not needed for join-heavy small-table queries.
- 2026-09-21 — No `fraction` table; fraction is a normalised string with one shared normalisation function. A table would add a join and nothing else.
- 2026-09-21 — `speech_paragraph` and `individual_vote` inherit provenance from their parent row (same raw file); every other table carries `source_url`, `source_document_id`, `retrieved_at`. Avoids repeating three columns 630× per vote.
- 2026-09-21 — One `rede` element with several speakers is split into several `speech` rows (`<rede id>-2`, …); presidency remarks inside a `rede` become `chair` paragraphs, not speeches. Keeps the clean-text unit one speaker, one voice.
- 2026-09-21 — Personal DIP API key requested by e-mail; the public key rotates and both known ones are expired. Until it arrives, DIP code is written against recorded fixtures only.
- 2026-09-21 — Name matching looks at Wahlperiode mandate holders first and at all known persons second. Nachrücker who joined after the Stammdaten file date have no mandate row yet but may already exist as persons.
- 2026-09-21 — Raw files get a `.meta.json` sidecar (url, retrieved_at); `ingest` reads provenance from there and never from the network. Keeps the store rebuildable offline.
- 2026-09-21 — DIP author activities are stored with their `activity_type`; the co-authored query does not filter on it yet. Which activity types `f.drucksache` returns is unverified until a key is available.
- 2026-09-21 — Ruff line length 120 rather than 100. SQL and f-strings otherwise wrap into unreadable fragments.
- 2026-09-21 — abgeordnetenwatch is fetched per Wahlperiode via a fixed `PERIOD_BY_WAHLPERIODE` map ({21: 161}); raw files are named `wp21-*.json`. One explicit mapping beats deriving the WP from mandate labels.
- 2026-09-21 — DIP calls stay sequential and `ingest` re-parses every raw file each run. Parallel fetching and change detection are cheap to add later; neither can be tuned without a key or a full Wahlperiode of data.
- 2026-09-21 — The protocol parser repairs one known upstream quirk: a speaker with two ids in one attribute and doubled name elements (Svenja Schulze in 21/18, 21/24, 21/25, 21/28, 21/44–46). First id wins, doubled strings are halved. Seen in 7 of 94 WP21 files; no other merged ids exist.
- 2026-09-23 — `bdf update` derives every fetch window from `data/raw/` instead of storing a state file. The raw files already are the state; a separate file could drift from them, and a missed week is caught up automatically.
- 2026-09-23 — `update` re-reads votes and DIP 14 days back and refetches Stammdaten and abgeordnetenwatch in full each run. Late publications are common, the full refetches are one file and ~15 requests, and ingest upserts idempotently.
- 2026-09-23 — Container image runs as uid 1000 with `BDF_DATA_DIR=/data`. Matches the host user, so a bind-mounted data directory is writable from both sides without chown.
- 2026-09-27 — Authorship means the DIP activity types Antrag, Kleine Anfrage, Große Anfrage, Entschließungsantrag, Änderungsantrag, Gesetzentwurf and Frage. `f.drucksache` also returns Berichterstattung (committee rapporteurs on a Beschlussempfehlung) and Antwort (government answers); both stay in `drucksache_author` with their type, but `query drucksachen` leaves them out. Observed on the 251 Drucksachen of 6–10 July 2026, the first week fetched with the personal key.
- 2026-09-27 — `author_count` takes DIP's `autoren_anzahl` unless the fetched activities name a different number of persons; then the activities win and `ingest` lists the Drucksache. In the first real week only 21/7052 (Schriftliche Fragen: 0 vs. 148 askers) disagreed; the list shows whether other types do after the backfill.
- 2026-09-27 — DIP test fixtures are recorded responses, trimmed to four Drucksachen, instead of synthetic ones. The real data differed from the spec-based guesses in details the tests pin (originator spelling `Fraktion DIE LINKE`, the vote's Drucksache as `21/6278, 21/7009`).
- 2026-09-27 — Backfill of the whole Wahlperiode (8,220 Drucksachen, 63,920 activities): Große Anfrage (227) appeared as a ninth activity type and counts as authorship. `autoren_anzahl` disagrees with the activities only on Schriftliche Fragen (75) and Fragen (15), always as 0; the activity count stays the rule.
- 2026-09-27 — Election results come from the Bundeswahlleiterin, not abgeordnetenwatch: the official returning officer, a named open licence (dl-de/by-2-0) and a "Stand" date to cite. Two files: the elected (`btw25_gewaehlte_utf8.zip`) and results per Wahlkreis (`kerg2.csv`). abgeordnetenwatch stays the source for its own data (cross-ids, citizen questions).
- 2026-09-27 — The election files are fetched once (only if missing) by `update`: they are final and have not changed since March 2025.
- 2026-09-27 — Elected candidates are matched to MdB ids with the shared name index, then each given name in turn, then a unique WP member with the same surname part and birth year. The official file lists legal names ("Joachim-Friedrich Martin Josef Merz", "Saleh, Kassem Taher"), the Stammdaten the names in use. On the real file 629 of 630 match; every match agrees with the Stammdaten on mandate type, Wahlkreis and birth year. "Stegeman" is an alias for Albert Stegemann. Ralf Schnurrbusch (AfD) stays unmatched: he has no Stammdaten record, vote or speech in the store.
- 2026-09-27 — `constituency.seat_party` is NULL where the Wahlkreis winner got no seat (23 Wahlkreise in 2025, no Zweitstimmendeckung). A list member's own first-vote share is not copied into `election_candidacy`; it is the party's Erststimme row in `constituency_result`. The two files agree on every constituency winner's share.
- 2026-09-28 — DIP list records (Drucksachen, Vorgangspositionen) are deduplicated by DIP id across range files before ingest, the most recently retrieved copy winning. `update`'s 14-day lookback makes consecutive range files overlap; counted twice, one Namentliche Abstimmung became two decisions for one vote and vote 21/96/1 lost its link after the first daily run on top of the backfill.
- 2026-09-28 — abgeordnetenwatch profile statistics go into `aw_profile` (profile URL, citizen questions, answered), one row per politician with provenance `aw politician <id>`. The counts are the profile's lifetime totals (`statistic_questions`), not per Wahlperiode; consumers must say so. Kept out of `person` so the Stammdaten upsert and the aw figures do not overwrite each other.
- 2026-09-28 — Interjections are parsed from the protocol's comment paragraphs into `interjection`, one row per actor of each part. Parts split at " – " only where a recognised part starts, because the quoted words contain dashes too. Actors: a whole fraction, some of its members ("bei Abgeordneten der"), a named person, the house. A person named with "an den/die Abg." is the addressee, not an actor (71 cases in WP 21, all matched). On the 95 WP 21 protocols: 143,574 rows; 0.2 % of parts unclassified (mostly stage directions like "Das Mikrofon wird abgeschaltet"); 51,459 of 51,467 named persons matched, the 8 misses are typos in the protocols ("Hedi Reichinnek").
- 2026-09-28 — A person's bracketed fraction is kept as printed at the time (Jan Wenzel Schmidt [AfD] before he left the fraction), not replaced by the current membership.
- 2026-09-28 — `raw.get` retries network errors (dropped connections, timeouts) like 429/5xx, and `update` isolates each source: one that still fails is skipped for the run, the rest are fetched and ingested, exit code 1. A single "Server disconnected" from abgeordnetenwatch had aborted the whole update, so DIP was not fetched and nothing was ingested.
